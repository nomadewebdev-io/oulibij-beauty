# OuliBij Beauté — Salon de Maquillage, Coiffure & Parfumerie à Dakar

Site vitrine et réservation directe sur WhatsApp du salon **OuliBij Beauté** (*« Prenez en main la beauté de votre regard »*), situé à **Cité Sonatel 2, en face UNO des 2 Voies, Liberté 6, Dakar**.

---

## Informations du Salon

- **Slogan** : Prenez en main la beauté de votre regard
- **Adresse** : Cité Sonatel 2, en face UNO des 2 Voies, Liberté 6, Dakar
- **Téléphone & WhatsApp** : 77 619 58 50 (`https://wa.me/221776195850`)
- **Horaires** : Lundi au dimanche, 9h – 21h
- **Services** :
  - **Maquillage** : cérémonie, simple et contouring
  - **Coiffure** : tissage, tresse, bouclage, pose lace, Stream Pod, teinture, soins
  - **Divers** : cosmétiques, parfumerie, accessoires

---

## Stack Technique

- **Framework** : Next.js 16 (App Router) + React 19 + TypeScript
- **Design** : Tailwind CSS v4 — Palette Noir & Or (ambiance luxe chaleureux)
- **SEO & Réseaux Sociaux** : Métadonnées Open Graph 1200x630, Schema.org `BeautySalon`, Sitemap XML et `robots.txt`
- **Mobile & Conversion** : Carte Google Maps intégrée, bouton d'appel direct et barre d'action WhatsApp / Appel flottante sur mobile

---

## Commandes Utiles

```bash
# Serveur de développement
npm run dev

# Générer la bannière Open Graph 1200x630 et les icônes Noir + Or
node scripts/optimize-assets.js

# Vérification linter & compilation de production
npm run lint
npm run build
```
